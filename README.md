# GARKO Releases

Ez a nyilvános tároló kizárólag a GARKO Windows-telepítő kiadási csatornája.
A program forráskódja privát repóban marad.

A telepített GARKO az `appcast.xml` fájlból ellenőrzi az elérhető verziót.
Minden telepítő Ed25519-aláírást kap, amelyet a program a letöltés után,
telepítés előtt ellenőriz. A GitHub Release vagy az appcast módosítása
érvényes aláírás nélkül nem eredményez telepíthető frissítést.

Kezdő verzió: `0.0.0`. Ehhez még nem tartozik Windows-telepítő; az első
valódi kiadás csak teljes Windows release-gate után jelenhet meg.
